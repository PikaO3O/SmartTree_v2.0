二、問題與應用目的

居家或校園盆栽經清潔、照護與搬動後，可能未回到可觀察的位置。本系統持續辨識畫面內是否有合格盆栽，藉由 LED、提醒及事件歷史協助檢查。第三週購入真實薄荷盆栽，將既有原型帶入實物場景；模型辨識的是盆栽外觀，不辨識薄荷品種、健康、缺水或澆灌需求。

三、系統設計與功能延伸

攝影機取得影像 → 板上 YOLOv7-tiny → 類別／分數篩選 → 真實結果、顯示框及存在狀態分流 → USB 畫面、LED、Confirm／Alert 與序列歷史。核心辨識在開發板執行，電腦負責觀看與文字紀錄。

設計v2.0 實作
影像工作獨立唯一工作管理攝影機、UVCD、通道與 OSD，沿官方 nnbegin() 流程；Arduino loop 處理 UART、LED 與存在狀態，不等待 USB 協商。
顯示與判斷分離真實結果更新綠色 LIVE；短漏判時顯示最多 600 ms 黃色 HOLD。暫存框不增加真實命中、確認次數或事件。
確認與事件保留保留 2 秒且至少 3 輪真實正結果確認、5 秒連續負結果提醒、LED、事件去重與最近 32 筆 RAM 歷史；新增可關閉的 1 秒漏判容忍。

不新增影格副本或影像通道；回呼以固定上限快照與非阻塞 queue 傳送，不重讀舊結果當成新推論。整張畫面內任一合格盆栽即可確認，尚未限定區域或追蹤同一盆栽身分。

四、材料、接線與 SDK／模型配置

項目設定與用途
材料AMB82-MINI／RTL8735B、原廠攝影機、板上 LED_B／LED_G；薄荷盆栽、固定架與距離尺。未連接水泵、感測器或補光燈。
開發環境Arduino IDE 2.3.10；Realtek Ameba Boards 4.0.9 正式版；Windows 11 相機。交付端以 CLI 1.2.2、f37、Flash、NN Logs Disable 編譯。
模型與目標DEFAULT_YOLOV7TINY、盆栽連續索引 58、信心門檻 0.50、NMS 0.30；沿用模型，未訓練。既有模型輸入資訊為 416 × 416。
AI／顯示通道 3：576 × 320 RGB、來源設定 10 fps，非實測推論速度；既有約 5 次／秒為使用者先前紀錄。通道 0：USB_UVCD_STREAM_PRESET，實際格式由主機協商。
USB 現有設定MJPG=1，YUY2／NV12／H264／H265=0，直接保留。preset 的 FHD／20 fps／H264 是協商前啟動配置，不代表強迫 Windows 使用 H264；無須修改套件。
一條線的用法只接 UART／燒錄口：上傳、115200 指令；只接 OTG（8735）：供電與 UVC 畫面，沒有 UART COM 埠。同時觀看與收集推論才需兩條線；換線若斷電，RAM 紀錄清空。

五、燒錄與操作步驟

① 下載完整 GitHub 專案，開啟 SmartTree/SmartTree.ino，同資料夾所有 .h／.cpp 保留。② 選 AMB82-MINI／4.0.9、正確 COM，感光元件沿用原先成功選項，模型選 Flash。③ 驗證、上傳並 RESET，確認封裝含 yolov7_tiny。④ 先以 UART 測 PING、STATUS，再接 OTG 開啟 Windows 相機。⑤ 盆栽先距鏡頭 20～30 cm、水平正對並固定，讓植物與花盆同時入鏡，避免強光與非必要遮擋。

六、狀態、計時與紀錄

狀態意義與燈號
DETECTED／HOLD綠 LIVE 是最近一輪真實命中；黃 HOLD 沿用上次位置最多 600 ms。邏輯到期後，下次約 100 ms OSD 更新移除；實際顯示延遲待測。
CHECKING／CONFIRMED確認中藍慢閃；滿 2000 ms 正證據且至少 3 輪真實正結果後綠燈。1 秒內漏判保留狀態、暫停正證據累積；不是靠 HOLD 完成確認。
NOT CONFIRMED5 秒連續負結果才提醒一次、藍恆亮；提醒後恢復才新增確認事件。原門檻不變；容忍設 0 可回復 v1.1。
TIMEOUT／OFFLINE1500 ms 無新回呼：NN DATA TIMEOUT、藍快閃；USB 離線：兩燈暗。無回呼不算盆栽消失，資料缺口或逾時需重新確認。

UART 設 115200／新行：PING、STATUS、HISTORY 保留；LOG ON/OFF、SAMPLES ON/OFF、STATS 與 STATS RESET 控制量測；OSD OFF/BOXES/FULL 用於隔離比較；USB RETRY 只人工重等一次協商，未保證恢復。STATUS 補 USB、NN、分數、FPS 與 MEM；SDK ready 不代表 Windows 已收到影格。歷史 RAM 滿 32 筆覆蓋最舊，重開機清空。

十一、限制與後續方向

螢幕圖片也可能被辨識，N05 的 Plants:2 不等於現場有兩盆；不辨別實物、圖片、植物健康或缺水，不能作為澆灌唯一依據。顯示框穩定不代表模型準確率改善。比較門檻時固定距離、光線與同一張圖片，每次只改一個變因，另測無盆栽場景；分開統計真實命中／漏判／誤判與框線可見時間。暫不換模型、不重新訓練；區域限制、感測器、補光與澆灌為後續方向。
